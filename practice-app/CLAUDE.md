# practice-app

A tiny task list used to practise the solo-review system. Node, no dependencies, data in memory.

- Start: `npm start` (PORT env var sets the port, default 3000). Test: `npm test`.
- Files: `server.js` (API and static page), `index.html` (the page), `test/` (tests), `specs/` (one folder per feature).
- There is no lint or build step. Write `none` for them in REVIEW.md.
